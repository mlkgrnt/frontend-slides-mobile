# Frontend Slides Mobile · 移动端卡片生产线

把任何内容变成**手机竖版卡片**，交付 **一组 PNG 图片 + 一个矢量 PDF**。
HTML 只是渲染源文件（保留它以便修改重渲染），**不是**交付物。

## 核心原则

1. **竖版优先**：默认 3:4（1080×1440），为手机一屏阅读设计；字号只跟画布宽度绑定。
2. **一屏一个观点**：超了拆卡，永远不为塞内容缩小字号。
3. **静态终态**：渲染是静态快照，所有装饰必须不依赖动画即成立（禁止入场动画的初始态）。
4. **Show, Don't Tell**：风格选择靠**渲染预览**让用户挑，不让用户空想抽象风格词。
5. **零依赖**：只用本机已装的 Chrome/Chromium/Edge，不装任何 npm 包。
6. **反 AI 俗套**：拒绝 Inter/紫色渐变/白底卡片堆这类"AI 味"默认值；
   每个 deck 从风格库里**有意识地选**一个方向。

## 交付物

| 产物 | 说明 |
| --- | --- |
| `cards/01.png … NN.png` | 一组图片，1080×1440（或所选画布），分享/发布用 |
| `deck.pdf` | 矢量 PDF（文字可选中可搜索、字体子集内嵌），阅读/转发/打印用 |
| `deck.html` | 渲染源文件（保留！改内容/颜色都改它，然后重渲染） |

## 工作流

### Phase 0 · 意图确认（一次问清，别挤牙膏）

尽量一次问完（有结构化提问 UI 就用，否则一条消息列出）：

1. **内容从哪来**：用户给主题 / 用户贴文章或文档 / 已有大纲。
2. **用途**：发布平台（小红书 / 公众号 / 微信分享 / 自存 PDF / 其它）→ 决定画布：
   - 小红书、公众号、微信分享 → `3:4`（默认）
   - 手机全屏 story、抖音/视频封面 → `9:16`
   - 方图场合 → `1:1`
   - 用户没概念 → 直接用 `3:4`，不再追问。
3. **张数期望**：默认建议 5–9 张（完整读完一屏组卡的舒适区间）。

**不要问**风格术语（"你想要什么设计风格？"）——风格在 Phase 2 用图说话。

### Phase 1 · 内容结构化

1. 读透内容（短文直接读；长文/文档先提炼核心观点列表）。
2. 拆成**卡片大纲**，套用容量规则（见 `references/canvas-and-type.md` §4）：
   - 卡型选 layout-patterns.md 里的 12 种（cover / bullets / statement / compare / stats /
     steps / quote / checklist / longform / image / section / closer）。
   - 默认结构：`封面 → (章节 → 2-4 张内容卡)×N → 收尾`。
   - 一张卡 = 一个观点；超字数就拆成两张，绝不缩字号。
3. **把大纲给用户确认**（每张卡的：类型 + 标题 + 要点摘要），确认后再生成。
   这是唯一的经济的返工点——大方向在这里对齐。
4. 内容超过 14 张卡 → 主动建议拆成"系列多组"（上/中/下），先出第一组。

### Phase 2a · 风格选择（Show, Don't Tell）

1. 按内容气质从 `references/style-presets.md`（12 个安全盘）挑 **3 个候选**；
   内容气质特别强烈时，可换 1 个来自 `references/bold-styles.md`（34 个个性盘）。
2. **用用户的真实内容**（封面标题 + 一句话副题）渲染 **3 张封面预览卡**：
   - 各写一个独立小 HTML（或一个 HTML 3 张卡），套候选的色板/字体，
   - `node <skill>/scripts/render.mjs preview.html --png-only --out-dir=previews`
     （只为出图，不需要 PDF）。
3. 把 3 张预览图呈现给用户，让 TA 挑（允许说"混合元素"）。
4. 用户没偏好时推荐默认：内容严肃选 `vellum`/`signal`/`Paper & Ink`；
   轻快选 `Pastel Geometry`/`Split Pastel`/`playful`。

### Phase 2b · 字体选择（同样 Show, Don't Tell）

风格定下后，中文字体也让用户用眼睛挑：

1. 读 `references/font-library.md`：按所选风格从 §3「风格 × 字体搭配表」拿**推荐组合**
   （显示字体 + 正文字体），再从同气质里挑 2–3 个备选。
2. 用**用户的封面标题**生成 **1 张字体对比卡**（1080×1440，纵向排 3 行：
   每行 = 字体名标签 + 同一句文案用该字体渲染），套所选风格的配色与明暗。
3. 渲染这一张卡（`--png-only`）呈现给用户，同时给出推荐组合说明
   （例如「标题用 霞鹜文楷 + 正文用 思源宋体」）。用户可直接采纳、单挑一款、或标题/正文分用两款。
4. 若用户不置可否 → 用搭配表的第一推荐，不再追问。

**约束**：只从 `font-library.md` 选字体（许可已验证）；一个 deck ≤2 个字族 + 1 个点缀字体；
想引入库外字体时，先过 font-library.md §0 的核查清单并征得用户同意。

### Phase 3 · 生成完整 deck

1. 以 `assets/deck-template.html` 为骨架（它含：舞台 CSS、单卡模式、打印模式、页码系统）。
2. **替换风格层**：把所选风格的色板写进 `:root` 变量（`--bg/--fg/--accent/--font-*`）。
3. **接入字体**：按 Phase 2b 的结果，从 `references/font-library.md` 复制对应的 CDN
   `<link>` 行进 `<head>`（基础级 Google Fonts + 选装级中文网字计划）；字体名后带全兜底栈。
4. 按 Phase 1 的大纲逐卡生成（骨架抄 layout-patterns.md 对应模式）。
5. **自检**（生成后逐张过一遍）：
   - [ ] 正文 ≥32px、标题 ≥68px、行高 ≥1.6
   - [ ] 每卡一个观点；要点 ≤5 条；正文卡 ≤180 字
   - [ ] 数字/英文与中文之间有空格；无中文斜体、无中文 uppercase
   - [ ] 装饰不遮挡文字；无动画依赖（静态即完整）
   - [ ] 页码 `data-pg` 在每张卡的页脚（自动填充，不用手写）

### Phase 4 · 渲染

```bash
node <skill>/scripts/render.mjs path/to/deck.html
```

- 产物：`cards/*.png` + `deck.pdf`（数量、尺寸、页数自动校验并报告）。
- 首次渲染会下载 webfont（较慢），之后每张 ≈1.4s。
- 报告里有任何 `⚠/✗`：查 `references/render-pipeline.md` §6 故障排查。

### Phase 5 · 交付

1. 把 **PDF + 图片组** 呈现/列出给用户（文件路径 + 张数 + 画布尺寸）。
2. 告知：
   - 修改方式：改 `deck.html` 后重跑渲染（30 秒内）；
   - `_render-cache/` 是字体缓存目录，可删；
   - 图片可直接发平台；PDF 适合转发与打印。
3. 主动问是否需要：调整文案 / 换风格（换 `:root` 变量重渲染）/ 换画布比例 / 拆系列。

## 常用速查

**画布**：3:4 = 1080×1440（默认）· 9:16 = 1080×1920 · 1:1 = 1080×1080 · 16:9 = 1920×1080（仅横屏场合）
**字号（1080 宽基准）**：封面 112–150 · 卡标题 68–84 · 小节 48–58 · 正文 36–42 · 小字 30–34 · 标签 24–28
**手机等效**：卡片文字等效 pt = px ÷ 2.77（正文 38px ≈ 13.7pt ✅；<32px ❌）
**容量**：要点卡 3–5 条 · 每条 ≤26 字 · 正文卡 ≤180 字 · 一行 ≤22 个汉字
**字体**：基础 = Noto Serif SC / Noto Sans SC（Google Fonts）；选装 = `font-library.md` 的
15 款开源中文字体（明朝/楷/黑/圆/手写/等宽/像素，Phase 2b 挑完从 CDN 引）；所有字体名后带兜底栈。

## 反模式（生成前必看）

- ❌ 交付 HTML 给用户（交付 = PNG 组 + PDF；HTML 是内部渲染源）
- ❌ 用入场动画/透明度渐显做效果（静态快照会丢帧或全空）
- ❌ 一屏两观点 / 缩小字号硬塞 / 正文 <32px
- ❌ 中文用斜体、uppercase、letter-spacing >0.02em
- ❌ 纯白 `#fff` / 纯黑 `#000` 大面积铺底（用带色偏的纸白/墨色）
- ❌ 风格全靠默认值不选（每条 deck 都要有意识选风格 + 选字体）
- ❌ 引入 `font-library.md` 之外的未验证字体（许可风险；要引入先过核查清单）
- ❌ 把 `_render-cache/` 当垃圾删掉又不重渲染（删了只是下次渲染慢一点，无害）
