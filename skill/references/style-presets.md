# 风格预设（12 个内置）· 移动端竖版适配版

12 个经过打磨的安全盘预设（改编自 frontend-slides / zarazhangrui，MIT）。
每个预设包含：气质 → 色板 → 字体（含中文配对）→ 竖版布局转译 → 签名元素。
**这是默认推荐盘**：不确定时优先从这 12 个里挑；需要更强烈的个性时去 `bold-styles.md`。

## 快速选择表（按内容气质）

| 内容气质 | 推荐预设 |
| --- | --- |
| 自信、冲击力、路演 | Bold Signal / Electric Studio |
| 活力、创意、年轻 | Creative Voltage / Split Pastel |
| 优雅、文艺、深度 | Dark Botanical / Paper & Ink |
| 安静、学术、理性 | Notebook Tabs / Swiss Modern |
| 友好、亲和、科普 | Pastel Geometry / Split Pastel |
| 科技、未来、数码 | Neon Cyber / Terminal Green |
| 幽默、编辑、观点 | Vintage Editorial / Bold Signal |

**竖版通用转译原则**（适用于全部预设，后文只写各自特有点）：
上游的**左右分栏 → 上下分区**；横向网格 → 单列流；标题区从"左上角"改为"上 1/3"；
导航面包屑 → 页脚迷你条；超大序号保留（竖版更显眼，是好东西）。

## 深色系

### 1. Bold Signal · 信号强音
**气质** 自信、高冲击、现代。深灰渐变底 + 一块高饱和焦点色卡。

**色板**
```css
--bg: #1a1a1a; --bg-2: #2d2d2d;   /* 深灰渐变两端 */
--card: #FF5722;                   /* 焦点色卡：橙 / 珊瑚 / 明黄 */
--fg: #ffffff; --fg-on-card: #1a1a1a;
```
**字体** 显示 `Archivo Black` · 正文 `Space Grotesk` → 中文标题 `Noto Sans SC 900`，正文 `Noto Sans SC 400`
**竖版布局** 焦点色卡占画布上 55–65%（满宽出血到左右边），标题压在色卡区域下沿；
下方 1/3 放副题（1–2 行）+ 署名。超大序号置于色卡内左上角。
**签名元素** 大章节数字（01/02）浮在色卡上；面包屑导航缩为页脚一行小字；
渐变底从 135deg 改为 180deg（竖向）。
**适合** 发布会、产品推介、演讲封面。**避免** 需要安静气质的场合。

### 2. Electric Studio · 电光工作室
**气质** 干净、专业、强对比。白蓝双色上下分屏。

**色板**
```css
--bg-dark: #0a0a0a; --bg-white: #ffffff;
--accent: #4361ee;                 /* 电光蓝 */
--text-dark: #0a0a0a; --text-light: #ffffff;
```
**字体** 显示+正文 `Manrope`（800 / 400）→ 中文 `Noto Sans SC 700` / `Noto Sans SC 400`
**竖版布局** 上方 58% 白区放标题与要点（深色字），下方 42% 蓝区放结论/署名（白字）；
分界线处放 8–12px 强调条（accent 色或反向对比）。
**签名元素** 双面板硬边交界；角标品牌标记（上下各一）；引文式大字。
**适合** 商务简报、方案汇报、FAQ 卡。

### 3. Creative Voltage · 创意电压
**气质** 活力、复古现代。电蓝 + 霓虹黄，半分屏。

**色板**
```css
--bg-blue: #0066ff; --bg-dark: #1a1a2e;
--neon: #d4ff00;                   /* 霓虹黄 */
--fg: #ffffff;
```
**字体** 显示 `Syne`（700/800）· 等宽 `Space Mono` → 中文 `Noto Sans SC 900` / `Noto Sans SC 400`
**竖版布局** 电蓝区占上 45%（标题 + 霓虹徽章），深色区占下 55%（要点列表）；
霓虹黄只做徽章、关键数字、分隔线。
**签名元素** 半调网点纹理（radial-gradient 点阵）铺在蓝区一角；霓虹色徽章胶囊；
手写感斜体英文点缀（仅拉丁文本）。
**适合** 创意方案、活动海报卡、年轻向内容。

### 4. Dark Botanical · 暗色植物
**气质** 优雅、精致、艺术。暗底上的暖色柔光。

**色板**
```css
--bg: #0f0f0f; --fg: #e8e4df; --fg-2: #9a9590;
--accent-warm: #d4a574; --accent-pink: #e8b4b8; --accent-gold: #c9b896;
```
**字体** 显示 `Cormorant`（衬线 400/600）· 正文 `IBM Plex Sans` → 中文 `Noto Serif SC 500` / `Noto Sans SC 300`
**竖版布局** 内容居中（竖版居中最稳）；模糊光斑（blur 80px+ 的圆形渐变）放上角与下角，
**装饰与文字零重叠**；一行细竖线从标题上方向下延伸。
**签名元素** 柔焦光斑、暖色点缀、意大利斜体签名（仅拉丁）、细线族。
**适合** 文化类、艺术、高端品牌、深度随笔封面。

## 亮色系

### 5. Notebook Tabs · 笔记本标签
**气质** 编辑感、条理、触感。深底上的米色纸卡 + 彩色索引标签。

**色板**
```css
--bg-outer: #2d2d2d; --paper: #f8f6f1; --fg: #1a1a1a;
--tab-1: #98d4bb; --tab-2: #c7b8ea; --tab-3: #f4b8c5; --tab-4: #a8d8ea; --tab-5: #ffe6a7;
```
**字体** 显示 `Bodoni Moda` · 正文 `DM Sans` → 中文 `Noto Serif SC 700` / `Noto Sans SC 400`
**竖版布局** 纸卡四周留 40–48px 深色边框（像深色桌面上放一张纸）；
**右侧标签列**（竖版天然优势：标签更多、文字竖排更舒服）标出当前章节；
左侧打孔装饰改为纸卡左缘的圆点列。
**签名元素** 纸卡微阴影；右侧彩色标签（竖排小字）；左缘打孔/横线纹。
**适合** 教程、清单、多章节知识卡、手账风。

### 6. Pastel Geometry · 粉彩几何
**气质** 友好、条理、现代。粉彩底上的白卡 + 竖向胶囊列。

**色板**
```css
--bg: #c8d9e6; --card: #faf9f7;
--pill-pink: #f0b4d4; --pill-mint: #a8d4c4; --pill-lavender: #9b8dc4; --pill-violet: #7c6aad; --pill-sage: #5a7c6a;
```
**字体** 显示+正文 `Plus Jakarta Sans`（700/800 / 400）→ 中文 `Noto Sans SC 700` / `Noto Sans SC 400`
**竖版布局** 白卡内缩 48–64px 浮在粉彩底上；胶囊列放卡内右缘（高度错落：短-中-长-中-短）。
**签名元素** 圆角卡（28–40px 圆角）软阴影；彩色胶囊列；角落小图标。
**适合** 科普、教程、育儿/生活内容。

### 7. Split Pastel · 粉彩分屏
**气质** 俏皮、现代、亲和。双色对分。

**色板**
```css
--bg-a: #f5e6dc; --bg-b: #e4dff0;   /* 桃 / 薰衣草 */
--fg: #1a1a1a;
--badge-mint: #c8f0d8; --badge-yellow: #f0f0c8; --badge-pink: #f0d4e0;
```
**字体** 显示+正文 `Outfit`（700/800 / 400）→ 中文 `Noto Sans SC 700` / `Noto Sans SC 400`
**竖版布局** 上桃下薰衣草（55/45）；网格点阵叠在下半区一角（6–8% 透明度）。
**签名元素** 双色对分；彩色徽章胶囊（带小图标）；圆角 CTA 按钮（可作"下一步"暗示）。
**适合** 清单、步骤、亲和力科普。

### 8. Vintage Editorial · 复古编辑
**气质** 机智、个性、编辑感。米色纸上的几何装饰。

**色板**
```css
--bg: #f5f3ee; --fg: #1a1a1a; --fg-2: #555555; --accent: #e8d4c0;
```
**字体** 显示 `Fraunces`（700/900 衬线）· 正文 `Work Sans` → 中文 `Noto Serif SC 900` / `Noto Sans SC 400`
**竖版布局** 内容居中偏上；几何装饰组（圆圈轮廓 + 短线 + 圆点）放页脚区上方，
像杂志栏目题花一样居中排一行。
**签名元素** 粗边框 CTA 方框（观点卡）；俏皮的对谈式文案；几何题花。
**适合** 观点分享、专栏、书评、幽默向内容。

## 特色系

### 9. Neon Cyber · 霓虹赛博
**气质** 未来、科技、自信。深空底 + 霓虹辉光。

**色板**
```css
--bg: #0a0f1c; --cyan: #00ffcc; --magenta: #ff00aa;
--fg: #e8f4ff; --fg-2: #7a8ba0;
```
**字体** 显示 `Orbitron` 或 `Chakra Petch`（替代 Fontshare 的 Clash Display）· HUD `JetBrains Mono`
→ 中文 `Noto Sans SC 700`（标题）/ `Noto Sans SC 300`（正文）
**竖版布局** 粒子/网格背景铺满（极低透明度），标题居中，辉光聚焦标题区；
四角放 HUD 角标（L 形线框），底部放状态行（等宽小字）。
**签名元素** 霓虹描边文字（text-shadow 辉光）；网格线；扫描线；HUD 角框。
**适合** AI/科技、数码产品、游戏、极客向内容。

### 10. Terminal Green · 终端绿
**气质** 开发者、黑客美学。全屏终端窗口。

**色板**
```css
--bg: #0d1117; --green: #39d353; --green-dim: #26a641; --fg: #c9d1d9; --fg-2: #8b949e;
```
**字体** 全部 `JetBrains Mono`（400/700）→ 中文 `Noto Sans SC 400`（保持等宽气质用 `Noto Sans Mono` 若可用）
**竖版布局** 顶部一行"终端标题栏"（三个圆点 + 路径）；内容像命令行输出逐行排列
（`$` 提示符 + 缩进）；底部光标块。
**签名元素** 扫描线叠层（3% 透明）；闪烁光标块（静态展示用常亮实心块）；
语法高亮式配色（注释灰、字符串绿）。
**适合** 编程教程、技术笔记、开发者社区内容。

### 11. Swiss Modern · 瑞士现代
**气质** 干净、精确、包豪斯。

**色板**
```css
--bg: #ffffff; --fg: #111111; --accent: #ff3300;
--line: #e0e0e0;
```
**字体** 显示 `Archivo`（800）· 正文 `Nunito`（400）→ 中文 `Noto Sans SC 900` / `Noto Sans SC 400`
**竖版布局** 可见网格（细线或点到为止）；内容**不对称**：标题压上偏左，
红色小块或数字压右下；巨量留白。
**签名元素** 可见网格线；红色几何块（1–2 处，克制）；非对称构图；大号留白。
**适合** 设计、建筑、品牌、极简主义内容。

### 12. Paper & Ink · 纸与墨
**气质** 文学、沉思、出版物质感。

**色板**
```css
--paper: #faf9f7; --ink: #1a1a1a; --ink-2: #6b6b6b; --accent: #c41e3a;
```
**字体** 显示 `Cormorant Garamond` · 正文 `Source Serif 4` → 中文 `Noto Serif SC 500/700` / `Noto Serif SC 400`
**竖版布局** 单列书页式；标题与正文之间用细横线（1px，accent 或 ink-20%）分隔；
引文块（左侧 4px 竖线 + 斜体气息的缩进）作为强调单元；首字下沉只用于长文卡。
**签名元素** 细横线族；引文块；页眉页脚的书刊元素（期号、页码用衬线小字）。
**适合** 读书笔记、长文精读、人文社科、书信体。

## 使用注记

1. **色值是起点不是终点**：微调（±10% 明度）以适配具体内容，但**不要**换色系。
2. **字体必须写全栈**：`"Syne", "Noto Sans SC", sans-serif` —— 别漏中文兜底。
3. 每个预设的 CSS 起步块变量名保持 `--bg / --fg / --accent` 等统一命名，
   方便直接填进 `assets/deck-template.html`。
4. 预览让用户挑时（show-don't-tell）：用**同一段真实内容**渲染 3 个预设的封面卡做对比。
